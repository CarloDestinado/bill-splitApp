# How to Add Your Image

## Step 1: Add Your Image
Place your illustration image file in this folder with the name: `illustration.png`

**Supported formats:** PNG, JPG, SVG, WebP

## Step 2: Image Recommendations
- **Dimensions:** 400x400px or more (for best quality)
- **Format:** PNG or SVG for transparency
- **File size:** Keep under 200KB
- **Content:** Illustration showing people splitting bills, collaboration, or teamwork

## Step 3: The app will automatically display it!
Once you place the image file named `illustration.png` in this folder, it will automatically appear in the login page on the right side.

## Example File Structure
```
public/
  └── images/
      └── illustration.png  ← Place your file here
```

## Tips
- Use a transparent background PNG for best results
- The image will scale automatically to fit the container
- The current design expects an illustration showing people/teamwork
